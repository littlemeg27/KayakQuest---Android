# KayakQuest Android

Original Android kayak-planning app. Built for Full Sail University Project and Portfolio V: Computer Science.

KayakQuest helps paddlers plan trips with location and river information. The newer Kotlin / Jetpack version lives in [PaddleQuestAndroid](https://github.com/littlemeg27/PaddleQuestAndroid).

## Features

- Trip planning for kayaking and paddling
- Location services
- Firebase work during the course build
- Weekly milestone folders from the class schedule
- Deployment assets for store / demo packaging

## Tech stack

| Layer | Tools |
|---|---|
| Languages | Java, XML / HTML resources |
| Platform | Android |
| Backend | Firebase (course integration) |
| Build | Gradle / Android Studio |

## Project status

Course project. Active development moved to **PaddleQuestAndroid**.

## Getting started

1. Clone the repo
2. Open the project in Android Studio
3. Add Firebase / Maps keys locally if required
4. Run the `KayakQuest` module

```bash
git clone https://github.com/littlemeg27/KayakQuest---Android.git
```
